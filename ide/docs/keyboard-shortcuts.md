# Keyboard Shortcuts

Michael IDE keyboard shortcuts. On macOS the primary modifier is **⌘ Cmd**; on
Linux/Windows it is **Ctrl**. The tables below use **Mod** to mean "⌘ on macOS,
Ctrl on other platforms" where applicable.

## General

| Shortcut | Action |
|---|---|
| `Mod+Shift+P` | Open command palette |
| `Mod+P` | Quick open (file picker) |
| `Mod+O` | Open folder |
| `Mod+S` | Save active file |
| `Mod+W` | Close active tab |
| `Ctrl+`` ` `` | Toggle integrated terminal |

## Editing

| Shortcut | Action |
|---|---|
| `Mod+Z` | Undo |
| `Mod+Shift+Z` | Redo |
| `Mod+F` | Find |
| `Mod+Alt+F` | Find and replace |
| `Mod+H` | Find and replace (alternative) |

## Navigation

| Shortcut | Action |
|---|---|
| `Mod+Shift+E` | Show explorer panel |
| `Mod+Shift+F` | Show global search panel |
| `Ctrl+Shift+G` | Show source control panel |
| `Mod+Shift+M` | Toggle problems panel |

## Source Control

| Shortcut | Action |
|---|---|
| `Mod+Enter` (in commit input) | Commit staged changes |

## Terminal

| Shortcut | Action |
|---|---|
| `Ctrl+`` ` `` | Toggle terminal panel |

## Monaco Editor (built-in)

The editor inherits all [Monaco / VS Code keyboard shortcuts](https://code.visualstudio.com/docs/getstarted/keybindings).
Common ones:

| Shortcut | Action |
|---|---|
| `Mod+D` | Add selection to next find match |
| `Mod+Shift+L` | Select all occurrences |
| `Alt+Up/Down` | Move line up/down |
| `Alt+Shift+Up/Down` | Copy line up/down |
| `Mod+/` | Toggle line comment |
| `Mod+Shift+K` | Delete line |
| `Mod+L` | Select line |
| `Mod+]` / `Mod+[` | Indent / outdent |
| `Mod+G` | Go to line |
| `F2` | Rename symbol |
| `F12` | Go to definition |
| `Alt+F12` | Peek definition |
| `Shift+F12` | Find all references |
