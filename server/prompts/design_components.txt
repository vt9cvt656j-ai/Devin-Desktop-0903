# michael-design 组件层：令牌、primitive、图标与排版

- `:root` 定义 background/foreground/card/popover/primary/secondary/muted/accent/destructive/border/input/ring/radius，`@theme inline` 映射 `--color-*` 和 `--radius-*`，`.dark` 覆盖同名 token。一次确定 base 中性、primary、radius 与标题字体；业务组件只使用语义类，不写散色。
- 栈与底座（本层唯一权威）：React + TypeScript + Tailwind v4 + **shadcn/ui**。shadcn 组件建立在 @radix-ui/react-* primitive 上，配 class-variance-authority 写 variant、clsx + tailwind-merge 组成 `cn()`（放 src/lib/utils.ts）、lucide-react 出图标；shadcn 原件放 src/components/ui/，业务区块放 src/components/sections/。Tailwind v4 是 CSS-first：令牌写在 CSS 的 `@theme inline` 里，**不要建 tailwind.config.js/ts 或 postcss.config.js，也不要装 postcss/autoprefixer/tailwindcss-animate**；蓝图里出现 `tailwind.config`/`theme.extend` 一律翻译成 `@theme inline`。
- 「官方 primitive」= 上面这套 shadcn/ui + Radix。有官方 primitive 就组合，不另造平行 Button/Input/Card。按需覆盖表单 button/input/textarea/label/checkbox/radio/select/switch/form/combobox/calendar，展示 card/badge/avatar/alert/skeleton/table/chart/carousel，导航 menu/breadcrumb/pagination/tabs/sidebar/command，浮层 dialog/drawer/sheet/popover/tooltip/sonner，以及 accordion/collapsible/scroll-area/resizable。禁止全量安装。
- Button 的 default/secondary/outline/ghost/link/destructive 都要有 hover、focus-visible、active、disabled；同一要求适用于真实可交互控件。
- 图标先做“业务概念 → 对象/动作/状态 → 图标名”映射，再从项目图标库、Lucide 或 iconify_search 选统一风格。AI 用 Bot/Robot/Cpu，自动化用 Workflow，订阅用 Mail/Inbox，安全用 ShieldCheck/Lock，分析用 Chart/Gauge，游戏用 Gamepad2。Sparkles/Wand 只表示真实闪光或魔法；按钮和工具栏不用位图、emoji 或临时手写 SVG。
- 正文使用高可读无衬线与 system-ui 兜底，标题选择有辨识度的展示体，如 Fraunces、Space Grotesk、Sora 或 Instrument Serif，避免整页默认 Inter。真实加载字体；字号按 12/14/16/20/24/30/36 建立阶梯，正文行高约 1.5、行宽不超过 70 字，数字使用 tabular-nums。
- 需要给用户比较方向时，只做 2-3 套 primary/radius/字体不同的令牌预览，不生成多张无依据 AI mockup 猜风格。
