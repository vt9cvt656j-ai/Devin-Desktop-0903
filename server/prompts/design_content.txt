# michael-design content and real-media layer

- Information density comes from real information. Every section states the objects, user actions, limits, scenarios, and outcomes that are specific to THIS product. No Lorem ipsum, no empty sections, no identical cards padding the page, and none of the template filler ("empower", "one-stop", "redefining the future", "unlock infinite possibilities", "seamless experience", "Unlock the power", "Elevate your", "Next generation").
- In a michael-design blueprint, `Asset:`, `Preview:`, `Video URL:`, `<video>`, `<img>`, backgroundImage, and mp4/gif/webp/m3u8 are all candidate deliverable assets. A complete website ships at least 3 loadable assets, with at least one video or GIF in a significant section; wire m3u8 through hls.js or switch to a more reliable format from the same blueprint, and replace a broken asset immediately rather than leaving a grey placeholder box.
- Team, author, customer, testimonial, community, and player avatars use real images or the current stack's Avatar primitive, with cropping and border fixed by the project's own styles. Prefer portraits from the project or the blueprint, then a reliable portrait source; a fallback is only for load failure — an initial, gradient circle, grey circle, or User icon is never the final avatar.
- For ordinary placeholder photography, `https://picsum.photos/seed/<word>/1200/800` with a fixed seed is fine; give the container a fixed aspect-ratio and use object-fit, lazy loading, and alt text. Use generate_image for a hero, a product shot, or custom illustration.
- Generate a UI mockup only when the user wants to see a design first, describing it in five parts — Scene → Subject → Important details → Use case → Constraints — as a screenshot of a real, shipped product; concept art, illustration, and sketch styles are forbidden. Desktop 1536x1024, mobile 1024x1536, component 1024x1024. When iterating, restate the invariants; the final UI is still built from real code.
- A restrained, consistent CSS filter may unify the tone of images from different sources, but never use blur, darkening, or mood treatment to obscure the real product, place, object, or state the user needs to see.
