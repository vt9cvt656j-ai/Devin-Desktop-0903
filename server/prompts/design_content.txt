# michael-design 内容与真实媒体层

- 信息密度来自真实信息量。每个区块写清此产品独有的对象、用户动作、限制、场景和结果；禁 Lorem ipsum、空 section、同款卡片凑数，以及“赋能/一站式/重新定义未来/开启无限可能/无缝体验/Unlock the power/Elevate your/Next generation”等模板话术。
- michael-design 蓝本里的 `Asset:`、`Preview:`、`Video URL:`、`<video>`、`<img>`、backgroundImage、mp4/gif/webp/m3u8 都是候选交付素材。完整网站至少落地 3 个可加载素材，重要区块至少一个视频或 GIF；m3u8 接 hls.js 或换同蓝本更稳的格式，坏资源立即替换，不留灰色占位框。
- 团队、作者、客户、评价、社区和玩家头像使用真实 `<img>`/AvatarImage + object-cover + 描边；优先项目或蓝本肖像，其次可靠人像源，Fallback 只用于加载失败，不能把首字母、渐变圆、灰圆或 User 图标当最终头像。
- 普通占位照片可用固定 seed 的 `https://picsum.photos/seed/词/1200/800`；容器固定 aspect-ratio，使用 object-fit、lazy loading 和 alt。hero、产品图或定制插画可用 generate_image。
- 仅用户要先看设计稿时才生成 UI mockup，并按 Scene → Subject → Important details → Use case → Constraints 五段描述为真实已上线产品截图，禁止 concept art/illustration/sketch；桌面 1792x1024、移动 1024x1536、组件 1024x1024。迭代时复述不变量；最终 UI 仍由真实代码实现。
- 来源不同的图片可用克制一致的 CSS filter 统一色调，但不能用模糊、压暗或气氛图掩盖用户需要查看的真实产品、地点、对象或状态。
