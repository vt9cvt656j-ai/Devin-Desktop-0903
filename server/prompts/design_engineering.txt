# michael-design UI 工程层

- 沿用项目现有 reset、layer、构建与样式约定。仅 Tailwind 项目需要注意：Preflight 后不要追加未分层的全局 `* { margin:0; padding:0 }`，确需基础样式放 `@layer base`。full-bleed 用当前栈原生方式实现全宽外层加受限宽内层，并检查超宽屏对称与文字裁切。
- 状态覆盖 hover/focus-visible/active/disabled/loading/empty/error/selected。使用语义标签、aria、键盘可达和 WCAG AA 对比度（正文至少 4.5:1）；移动端同样精致，无横向溢出、文本裁切或控件重叠。
- 资源懒加载，长列表虚拟化，动效目标 60fps 并尊重 reduced-motion。深浅主题使用同一组变量；固定格式控件、网格、工具栏和卡片用稳定尺寸、grid track、aspect-ratio 或 min/max 约束，动态内容不能推动布局跳动。
- 文本必须适配容器并合理换行；紧凑面板使用紧凑字号，hero 级字号只用于真正 hero。不要按 viewport width 缩放字体，不使用负 letter-spacing。
