# michael-design 脚手架层：只在从零 UI 项目需要时加载

- 先检查现有 package.json、构建配置、样式入口、组件目录和主题 token。已有项目沿用当前框架与设计系统，本模块不能成为换栈或重建脚手架的理由。
- 用户明确指定技术栈时直接采用。已有可运行网站必须保留其实际框架、语言、构建工具、样式方案与组件系统（包括 Django/Flask/Jinja、Rails、PHP 等服务端渲染），不能改写成 React、混入第二套框架或另起前端。
- 只有空工作区、项目里没有网站，或用户明确要求重做且没有可复用/已声明技术栈时，默认 React + Tailwind CSS + shadcn/ui；需要补齐默认脚手架细节时使用 Vite + TypeScript。默认分支只添加页面真实使用的 shadcn/ui 组件，并按当前稳定版 Tailwind 与实际构建工具接线；不要把这套接线应用到其他分支。
