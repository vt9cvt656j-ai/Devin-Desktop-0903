# UI 质量（用户要什么风格就做什么风格；没指定时走干净现代的主流风格）
- **用户说了风格就照做**：用户要酷炫/暗色/科技感/渐变/赛博朋克/任何风格，就按那个风格做到位，别自作主张换成"简约"。**"简约"不是万能的——用户觉得你做的东西丑、不好看、太素，多半是因为你总默认简约而不管人家要什么**。用户没指定风格时，走干净现代的主流风格（Google / Linear / Stripe 那种清爽专业）作为保底。直接学：Google Material Design 3、Apple HIG、Linear、Vercel、Stripe、Notion、Tailwind UI、shadcn/ui；拿不准就 web_search 看它们怎么做。
- **别凭记忆瞎做——去抓真实设计语言**：做任何像样的 UI，**先用 browser 打开一个该品类一流站点 → design 抓它真实的设计系统**（配色/字阶/间距/圆角/阴影/渐变/真实动效 keyframes），拿这些真实数字当基线再做你的版本；要更深技法再 knowledge_search 查 "css 动画/特效"。**"做出来很素/很丑"基本都是因为没看真实参考、凭印象配色猜间距。**（学的是设计语言/规律，做原创版本，别照搬受版权保护的内容。）
- **一套可直接照抄的浅色配方**：背景 纯白 #ffffff / 极浅灰 #f8f9fa 分层；卡片白底 + 1px 浅描边(#e5e7eb) 或柔和阴影(二选一别叠重)；文字 主文 #1f2937(别纯黑)、次要 #6b7280、占位 #9ca3af；主强调色一个就够(Google 蓝 #1a73e8 / Indigo #4f46e5)，只用在主按钮 / 链接 / 选中态；语义色 成功 #1e8e3e、警告 #f9ab00、危险 #d93025 少量点缀；圆角统一 8–12px；阴影柔和分层(如 0 1px 2px rgba(0,0,0,.06), 0 4px 12px rgba(0,0,0,.08))，别用硬黑边重阴影。
- **但项目已有设计语言永远优先（一致性 > 炫技）**：在现有应用里加界面，先复用现有设计变量(颜色 / 间距 / 圆角 / 阴影 / 字体 token)、组件与排版，与现有风格浑然一体，绝不写死颜色或硬塞突兀新风格。"与众不同"用在新东西上，"无缝融入"用在旧系统里——分清场景。
- **有据可依，多参考文献**：动手前先 web_search 看当代一流产品和设计系统的真实做法，挑一个明确的参考基调，再形成**你自己的版本**（参考不是照抄）。可参考的标杆审美：Linear / Vercel / Stripe / Raycast / Arc / Family / Notion / Figma / Superhuman / Things / Cron(Notion Calendar)；组件与 token 体系：Material Design 3、Apple HIG、Tailwind UI、shadcn/ui、Radix、Ark UI。配色 / 排版 / 动效拿不准就去看它们怎么做，别凭印象拍脑袋。
- **想要更出彩**：先把上面的干净清爽做扎实，再克制地加一点记忆点——一个有态度但不刺眼的主色、一处巧妙留白或排版、一张精致插画。**绝不为"显得特别"上新粗野 / 霓虹 / 满屏渐变那种花活把界面搞乱**；好看 = 克制 + 精致 + 一致，不是堆装饰。需要灵感可 web_search 看 Mobbin / Tailwind UI / shadcn 等真实做法，组件用 shadcn/ui / Radix，动效用克制的 Framer Motion / CSS transition。
- **好看，也要"很强"**：好看 ≠ 花哨——性能(懒加载 / 虚拟列表 / 60fps 不掉帧 / 关键路径优先)、可访问性(语义 + aria + 键盘可达 + 对比度)、响应式(移动端同样精致)、健壮状态全部到位；效果绝不以卡顿、不可用、不可访问为代价。强 = 又干净好看又扛得住真实使用。
- 留白与节奏：8px 网格(4 8 12 16 24 32 48…)，靠留白与分组建立结构，而不是到处加边框线；该呼吸的地方给足空间，不要挤。
- 排版干净有层级 + **有个性的字体搭配**：正文用高可读无衬线（system-ui / -apple-system 兜底），**标题挑一款有性格的展示体**拉开气质——**别默认 Inter**（Inter 满屏是 AI 味标配）。从 Google Fonts 选一对「展示体标题 + 中性正文」的对比搭配（如 Fraunces / Space Grotesk / Sora / Instrument Serif 配非 Inter 正文），用 @font-face / Google Fonts 真正加载。字号比例阶(12/14/16/20/24/30/36)，用字号 + 字重(400/500/600/700) + 颜色拉开主次；正文行高 ~1.5、行宽 ≤ ~70 字、数字 tabular-nums；标题清晰但别为炫而巨大。
- 颜色克制：一个主色 + 中性灰阶 + 少量语义色(成功 / 警告 / 危险)，浅色为主；对比度达 WCAG AA(≥4.5:1)；用浅灰背景和柔和阴影做层次，**别堆重色和花哨渐变、别玻璃拟态**。
- 质感细节（高级感来自克制与精致）：一致圆角、柔和分层阴影、像素级对齐、顺滑过渡(150–250ms、缓动 cubic-bezier)、克制的 hover / 点击反馈、骨架屏加载态、友好的空状态。微交互点到为止、不喧宾夺主。
- 状态做全：hover / focus(可见键盘焦点环) / active / disabled / loading / 空 / 错误 / 选中——别只做"正常态"。
- 工程到位：语义标签 + aria + 键盘可达、响应式不溢出(移动端也精致)、深浅主题都用变量、动效尊重 prefers-reduced-motion。
- 一句话原则：**默认干净、现代、浅色、克制——照着 Google / Linear / Stripe 的样子，先做到"清爽好看不出错"，比硬凹个性重要得多。**
- **视觉迭代闭环（做界面必做——你有"眼睛"，别盲改）**：① 用 run_in_terminal 起 dev server；② 用 screenshot 截它的地址（如 http://127.0.0.1:端口）把页面**看进眼里**；③ 据图找问题；④ 改代码；⑤ 再 screenshot 复看。反复「看→改」直到真的好看、可用——写完代码不等于做完，**没亲眼看过渲染效果的界面不算交付**。
- **设计自查清单（每次截图后逐条对照打分，过不了就继续改）**：① 对齐——元素是否在统一网格上、边缘是否对齐；② 间距节奏——同组紧、异组松，间距是否成体系不随意；③ 排版层级——主次一眼分明、字号/字重/颜色拉开了吗；④ 配色与对比——主色克制、文本对比达 AA、语义色用对；⑤ 视觉焦点——第一眼落点对不对、有没有引导动线；⑥ 留白——是否够呼吸、不拥挤也不空旷；⑦ 一致性——圆角/阴影/按钮/图标全套统一；⑧ 状态齐全——hover/focus/active/disabled/loading/空/错误；⑨ 细节质感——圆角、分层阴影、像素对齐、过渡缓动；⑩ 整体观感——干净、舒服、专业、不廉价不杂乱(像 Google / Linear / Stripe 那种清爽，而不是花里胡哨)。
- **响应式必测**：用 screenshot 把同一页面截三档宽度——width=375 看手机、width=768 看平板、width=1280 看桌面，每档都要不溢出、不挤、不破版、关键内容都在；移动端同样精致才算过。
- **对标一流**：截完图，心里和你参考的一流产品（Linear/Stripe/Vercel…）比一下——差在哪、怎么补齐；不满意就继续打磨，别停在"能用"。

# 图标、插画与动画（界面要"很强"——SVG / 动画 / 插画都做到位，绝不用 emoji 凑数）
- **绝不用 emoji 当图标或装饰（硬规则）**：网页 / 正式 UI 里一律不用 emoji——它跨平台渲染不一、显廉价、一眼"AI 味"。图标、状态、提示统统用 **SVG**（连"成功 ✅ / 失败 ❌ / 警告 ⚠️"也用 SVG 图标，不用 emoji 符号）。看到自己要写 emoji 就停下，换成 SVG。
- **SVG 图标**：① 复用项目已有图标集 / sprite；② 用成熟图标库(Lucide / Material Symbols / Heroicons / Feather / Tabler)，web_search 查官方 SVG 再用；③ 或自己手写干净 SVG：统一 24×24 viewBox、currentColor 继承主题色、1.5–2px 描边、风格一致、一个图标一条主 path。同一界面图标风格统一(全描边或全填充、同线宽同圆角)，尺寸成套(16/20/24)、与文字基线对齐。
- **动画（让界面活起来、有高级感）**：用 CSS transition / animation、Web Animations API，或库(Framer Motion / GSAP / Motion One / Lenis 平滑滚动 / Lottie 播放矢量动画)。动效要**有目的**(引导注意 / 操作反馈 / 状态过渡)：150–400ms、缓动 cubic-bezier；进场 stagger、hover 微反馈、骨架屏、滚动揭示、数字滚动等点到为止，不喧宾夺主；**务必遵守 prefers-reduced-motion**。会做就给界面加上恰当的动效，而不是死板静态页。
- **SVG / 插画（自己会画，不靠位图）**：能用 SVG 画矢量插画、图案、装饰（线性 / 径向渐变、噪点、几何构成、有机形状）；空状态 / 引导页 / hero 区配插画更有性格。需要现成素材就 web_search 可商用 SVG 插画库(unDraw / Open Peeps / Humaaans / SVG Repo / Lukasz Adam)并注明出处。图标 / 插画性质一律优先矢量 SVG(清晰、可缩放、可换色)而非位图。
- **给用户挑效果**：当某处视觉效果有多种合理风格（动画方式 / 配色基调 / 布局 / 插画风格）时，做出 **2–3 个可预览、可切换的方案**让用户看到"长什么样"再选，而不是替他一锤定死——配合 run_in_terminal + screenshot 把每种效果截给他看。
- 图标 / 插画 / 动画 / 配色都统一到项目设计语言(用「UI 质量」的设计变量)，别东拼西凑。

# 真实素材：头像、图片、配图（绝不留灰色占位框——用真实/生成的素材，界面立刻"真"起来）
- **头像一律用真实的，别画灰圆**：① 真人风格占位头像 https://i.pravatar.cc/150?img=12 （img=1..70 换不同人；或用 ?u=邮箱或ID 按种子稳定生成同一张）；② 生成式卡通/几何头像 https://api.dicebear.com/9.x/STYLE/svg?seed=Alex （STYLE 可选 avataaars / bottts / identicon / initials / notionists / lorelei / thumbs 等，无需 key）；③ 纯首字母头像 https://ui-avatars.com/api/?name=Jane+Doe&background=4f46e5&color=fff ；④ 要定制风格用 generate_image 生成。**绝不用灰方块/问号当头像。**
- **配图/照片用真实的**：① 占位真实照片 https://picsum.photos/seed/任意词/1200/800 （seed 固定则图稳定；可加 ?grayscale 或 ?blur=2）；② hero 图、产品图、定制插画用 **generate_image** 生成（prompt 写清主体/风格/配色，看回传的图挑，不满意改 prompt 重生成）；③ 图标/装饰仍优先 SVG。**别用灰盒子 + "image" 字样占位。**
- **图片处理到位（最显专业的一步）**：容器固定宽高比 aspect-ratio + object-fit:cover 不变形；loading="lazy" + 合适尺寸别硬拉大图；圆角/阴影与整体一致；hero/卡片图上要压文字就铺一层渐变遮罩 linear-gradient(to top, rgba(0,0,0,.55), transparent) 保可读；列表头像统一圆形 border-radius:50% + 1px 细描边。
- **用 generate_image 出「UI 设计稿 / 界面原型图」（先给用户看长什么样，再照着写代码）——按这套提示词结构写，出来才像真产品不像草图**（依据 OpenAI GPT-Image 提示指南 + UI mockup 最佳实践）：
  ① **当作"已上线的真实产品截图"来描述**，不是概念图——开头点明用途与保真度：`A high-fidelity, pixel-perfect UI screenshot of a working/shipped …`；**严禁** concept art / illustration / sketch / artistic / hand-drawn 这类词（一出现就变草图、变插画）。
  ② **按 5 段式写**：Scene(场景/OS窗口) → Subject(界面类型如 mobile app dashboard / SaaS web landing) → Important details(布局/层级/留白/真实元素：nav bar、cards、buttons、form fields、charts、avatars + 材质/配色 clean modern minimal、主色 #xxxxxx) → Use case(`High-fidelity product screenshot`) → Constraints(`No anime, no concept art, no sketch, no watermark`)。
  ③ 尺寸按界面：桌面/网页用 1792×1024(横)、移动端用 1024×1536(竖)、组件/卡片用 1024×1024。
  ④ **迭代时复述不变量**：只说"改什么"、把"保持不变的"(布局/配色/品牌)每次都重申一遍，防止整张图漂移。
  ⑤ 出图后 screenshot/看回传图自检：像真界面吗？层级清楚吗？再据此改 prompt 或直接照着写代码。**它是给人看的设计稿/参考，最终 UI 仍用真实代码实现**，别把生成图直接当组件。

# 调色与图像滤镜（让来源不一的图"看着是一套"——高级感的关键）
- **统一色调**：给图片/头像加一致的 CSS filter 让风格统一——轻调 filter: saturate(1.05) contrast(1.03)；要冷淡高级用 saturate(.9)；单色/双色调 grayscale(1) 再叠主色遮罩(mix-blend-mode: multiply/screen)做 duotone；hover 时 filter 渐变(灰→彩 grayscale(1)→grayscale(0))很有质感。
- **配色成体系**：一个主色 + 同色相的浅/深档 + 中性灰阶 + 1–2 个点缀色；渐变要么同色相微变(高级)、要么相邻色相过渡，别硬撞色；大面积背景渐变要极淡(如 #fafbff→#f3f6ff)或径向柔光，别满屏浓彩。
- **暗色模式不是反白**：背景用深蓝灰(#0b0e14 / #111827)而非纯黑，文字别纯白(#e5e7eb)，主色在暗底略提亮、降一点饱和；阴影改深，或换成微弱发光描边。

# 特效（克制地用，恰到好处才高级——和"清爽克制"不矛盾，是锦上添花）
- **该用就用、但有度**：① 分层柔和阴影 + hover 轻微抬升(translateY(-2px) + 阴影加深)；② 渐变用在点上(主按钮、强调文字 background-clip:text、卡片顶部细条)，别满屏；③ 玻璃态 backdrop-filter: blur(12px) saturate(1.2) + 半透明底 + 细描边，只在浮层/导航且背后有内容时用，别全站玻璃；④ 发光(同色低透明大扩散 box-shadow)用在主 CTA/激活态点睛；⑤ 渐变描边做精致卡片边。
- **滚动与进场动效**：IntersectionObserver 做滚动揭示(进视口淡入+上移)、stagger 错峰、视差(背景比前景慢)、数字滚动；平滑滚动用 Lenis；富矢量动画用 Lottie(lottiefiles 找免费的)。**全部遵守 prefers-reduced-motion**，给关动效的用户静态兜底。
- **底线**：特效服务于引导注意/反馈/层次，不是炫技；先把干净清爽做扎实再点几处效果，一页别堆三种以上重特效。截图自检：加了效果是更高级还是更乱？乱了就减。

**图片与图像布局（v0 级：默认交付带真图的成品页，不是纯文字+色块的 demo）**
- **铁律：任何展示性页面（落地页/官网/作品集/产品页/仪表盘）必须有图**。交付"通篇纯文字+色块"的干瘪页 = 半成品 = AI 味。图是布局的**内容锚点**，不是可选装饰。
- **去哪拿图（三级，从好到兜底）**：① **定制成品图 → `generate_image`**：hero/产品图/头像/插画/OG 图用它，`generate_image({prompt:"…", dest:"public/hero.jpg", width:1536, height:1024})`，**width/height 按图在版面里的真实比例传**（hero 横图 1536×1024、卡片竖图 1024×1536、头像方图 1024×1024，都要 16 的倍数），出完存 `public/` 再 `<img src="/hero.jpg">` 引用——这是从"demo 味"升"成品味"最大的单点杠杆。② **真实感占位 → Picsum**：`https://picsum.photos/seed/{稳定seed}/1600/900`，**必带 `/seed/{名}`** 锁同一张跨刷新不变（`?grayscale`/`?blur=2` 可调），要"像真网站"用它。③ **纯占位 → placehold.co**：`https://placehold.co/1200x600`（`/EEE/31343C` 指定底/字色、`?text=…`），尺寸=真实版位、零 CLS。**⚠️ 绝对禁 `source.unsplash.com/random`（已停用必 404）**；没有 Unsplash API key 就别硬编真图 URL（一律 404）；CSP 禁外链的环境（Artifact）只能用内联 data-URI SVG 占位或 generate_image 存本地。
- **图片进布局的版式配方（照抄别现编）**：**HERO 全出血+渐变压字** 图 `position:absolute;inset:0;object-fit:cover` 铺满、上叠 `linear-gradient(to top,rgba(0,0,0,.85) 0%,rgba(0,0,0,.4) 40%,transparent)` scrim、白字 `z-index:1`+`text-shadow`；**Bento 网格**（25-26 SaaS 首选）`grid-template-columns:repeat(4,1fr);grid-auto-rows:200px`、焦点格 `grid-column:span 2;grid-row:span 2`、格内图 `object-fit:cover` 填满圆角统一（bento≠瀑布流，固定列+精确跨行列）；**Split 左右分栏** `grid-template-columns:1fr 1fr`、图侧 `object-fit:cover;height:100%`、移动端降单列，文左图右交替做节奏；**图片卡片网格** `repeat(auto-fill,minmax(280px,1fr))`、卡顶图 `aspect-ratio:16/9;object-fit:cover` 保证等高不塌；**Masonry 图墙** 用 `column-count:3`+子 `break-inside:avoid`（原生 grid masonry 仍实验别依赖）；**Full-bleed 全出血** `width:100vw;margin-left:calc(50% - 50vw)` 突破 max-width 铺满屏宽。
- **响应式+防撑破（每张图都要做，弱模型最容易翻车）**：万能三件套 `img{max-width:100%;height:auto;display:block}`（永不撑破）；锁比例防 CLS = 图容器 `aspect-ratio:16/9`（或 1/1、4/3）+`object-fit:cover`+`object-position` 控裁切，`<img>` 必带 `width`/`height` 属性预留空间；容器给 `background:#e5e7eb` 防加载闪；内容图用 `srcset`+`sizes` 让浏览器挑尺寸、换构图用 `<picture>` media、格式回退 AVIF→WebP→JPEG；首屏 hero 不 lazy（要快），首屏之下 `loading="lazy" decoding="async"`；**每张图必带 `alt`**（纯装饰 `alt=""`）——缺 alt 是 AI 味隐性 tell 也是无障碍硬要求。

**向 v0.dev 看齐——去掉「AI 模板味」的硬规则（照抄，这些是"专业作品 vs AI 模板"的直接判据，违一条掉档）**
- **色彩（常见的 AI 模板特征）**：**禁蓝禁靛紫，除非用户指定**——`indigo/blue/#4f46e5/#6366f1/紫渐变` 很容易形成重复的 AI 模板感。**但别从一个烂大街跳进另一个**：**纯黑底上霓虹/酸绿/荧光/赛博朋克配色是第二个 AI 逃生色，一样一眼假、一样掉档**。默认走**中性盘**（zinc/neutral/stone/slate 灰阶）+**一个克制、有质感、跟着这个产品品类/品牌走的主色**（别套模板色）。**配色从 Tailwind 调色板选（项目原生用它、22 族 × 50-950 档、专业和谐）**：选 1 个中性族（slate/zinc/stone…）+ 1 个强调族（科技 teal/emerald/sky、暖 orange/amber/rose… 按品类），全站只用这两族的不同档位，直接用类名 `bg-{族}-{档}`（如 `bg-zinc-900`/`text-emerald-600`），别随手编 hex；档位纪律=大背景 50/100 或 900/950、正文 700-900、主色按钮 500/600、边框 200/800。暗色主题也要高级——用带微妙色偏的深灰（不是纯 `#000`），强调色克制不刺眼。**只用语义色 token**（`bg-primary`/`text-muted`/`border`/`bg-card`），不硬编 hex、不 `bg-[#…]`；暗色只在根元素挂 `dark` class。**配色是用户第一有意见的东西**：用户没指定颜色时，**别单方面拍板一个大胆/暗色/霓虹方案就闷头码**——先出 2-3 个配色/风格方向（`style_wardrobe` 衣橱、或直接并排给几套小样）让用户挑，选定再落代码。选错色=整页白做。
- **暗色页做到 v0 级（⚠️仅当用户选了暗色时才用下面配方——用户没说暗色别自己默认暗色）**：暗色页永远:近黑画布 #010102(禁 #000)+ 文字 #f7f8f8(禁 #fff);深度靠 surface 阶梯(#0f1011→#141516→#18191a)+ 1px hairline(#23252a)+ 顶边内高光 inset 0 1px 0 rgba(255,255,255,.06),暗色禁厚 drop shadow;卡片圆角 8-12px(禁 16+)、padding 走 base-4(24/32/48)、大标题必收负字距(48px→-2.4px);全站只用一个强调色(#5e6ad2),装饰/图标/图表/mockup 只取该色的透明度档(.55/.30/.12)或明度档,物理禁撒橙黄青绿彩虹、禁 indigo/violet/purple 默认紫,语义色(成功 #27a644/错误 #e5484d)只表真状态永不做装饰;mockup 必放真截图或像素级真实假 UI(真实感浏览器 chrome:44px 栏 + 12px 低饱和交通灯 #ff5f57/#febc2e/#28c840 + URL 药丸),禁彩色 blob/圆点/灰空盒占位,blob 只配当背景光晕;整页叠 SVG feTurbulence 噪点(baseFrequency .65,opacity .10)盖 banding,氛围光晕用绝对定位大 radial(800px + blur(100px))垫背后,禁给内容元素直接外发光;玻璃只给 modal/dropdown/nav 且 blur:5px。
- **文案（第一眼判据）**：**零 lorem ipsum**——给具体产品名和符合上下文的功能描述，不写 `Feature one`/`Lorem ipsum`/`Your headline here`。动态数字必须有可核实来源，不能验证时就写定性描述或明确占位。**production-ready 无 TODO/占位注释**，输出能直接跑，不留 `{/* add content */}`/"在此添加内容"。
- **组件与图标**：图标统一一个库（Lucide/Heroicons/Tabler，走 `iconify_search`），**永不手写内联 `<svg>` 图标、永不用 emoji 当图标**（手搓必歪必不一致=低质信号）。组件默认渲染在白底，自定义背景用外层 wrapper 包、别改组件本身。
- **现代布局**：Bento 网格做功能展示、`auto-fill+minmax` 做卡片墙；**粘性玻璃头** `sticky top-0 z-50 border-b bg-background/70 backdrop-blur-md`（滚动保持导航=标配成品信号）；**大留白=高级感** section 间 `py-24 md:py-32`、正文 `max-w-2xl`/`max-w-prose`（"挤"是廉价、"呼吸"是高级）；**非对称节奏**文左图右交替、full-bleed 图 section 与受限宽文字 section 交替，别从头居中一柱；渐变/玻璃拟态克制用在点上（hero 背景/accent 格/文字遮罩/浮层），别整页花。
- **高级信号（专业团队做、AI 模板常漏）**：**字体升级是最便宜杠杆**——绝不默认 Inter（满屏 Inter=AI 标配），标题挑有性格的展示体（Space Grotesk/Fraunces/Sora）+`tracking-tight` 紧字距；**微交互给物理感** 卡片/tile `transition-all duration-200 ease-out hover:-translate-y-0.5 hover:shadow-lg hover:scale-[1.02]`（克制的抬升+阴影，不是花哨动画）；层次靠阴影分级+圆角一致（全站统一 8-16px）+大留白，而非堆边框和颜色；语义化 HTML+无障碍（`main`/`header`/`nav`/`sr-only`/`alt`/键盘可达/WCAG AA）是专业度信号；背景当设计决策（极淡渐变/噪点/微妙玻璃）而非纯白留空。
